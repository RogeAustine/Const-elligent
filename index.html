演示说明

本项目为 可离线运行 的智能体原型：默认使用内置的确定性推理器（rule-react），在无网络、无 API Key 的条件下即可完整跑通「目标拆解 → 工具调用 → 跨域关联 → 决策建议」全流程。

项目、传感器读数、组串数据与工友信息均为虚构演示样例；工程判定规则来自公开规范条文（GB / JGJ 系列），但最终验收与停复工决定必须由持证人员签字确认。

可在「设置」中切换到 DeepSeek / 通义千问 / 智谱 GLM / 本地 vLLM 等在线模型，切换后推理轨迹与工具调用协议完全一致。
