# 技术说明

## 实现范围

见仁建智的第一个可运行切片是 BIPV 绿能运维。选择依据是申报书明确提出的“运行数据 → 故障知识 → 维修工单”链路，能够以有限数据验证完整交互。当前只有一个 Agent，以本地规则为执行策略，模型解释为可选能力。

## 数据流与执行机制

浏览器通过同源 HTTP 调用本地服务。用户选择合成回放数据或上传 CSV；服务校验数据并保存。`Agent.create_run` 创建检查记录，后台线程执行最多五个本地步骤（启用模型时增加一个解释步骤），浏览器轮询结果。程序没有伪造耗时的动画延迟，每条工具记录在实际步骤执行后写入。

| 工具 | 输入 | 输出 |
|---|---|---|
| plan_inspection | 用户任务、设备集合 | 全站或指定 PV 编号范围、执行计划 |
| inspect_telemetry | 已校验遥测 | 样本数、时间范围、SHA-256 截断指纹 |
| normalize_and_detect | 设备最近样本、演示参数 | 归一化指标、异常或观察原因 |
| retrieve_handbook | 异常类型集合 | 精确匹配的手册条目与 KB 编号 |
| draft_work_orders | 持续异常与匹配手册 | 草案、三条原始证据、建议动作 |
| explain_with_model | 任务与最小测量摘要 | 可选的模型解释；失败不丢弃本地结果 |

没有外部工具任意执行功能。任务输入与模型输出不能执行 shell、绕过审批或触发真实设备操作。

## 状态流转

检查记录：`running → done / failed`。服务重启后，遗留的 running 标记为 failed，提示重新检查。

工单：`draft → 人工确认 → open → 复测通过 → closed`。复测不通过时保持 open；原始样本始终保留。审批使用 SQLite `BEGIN IMMEDIATE` 事务与草案唯一约束；同一草案重复点击返回同一工单，同数据集同设备同类型的未关闭工单不重复创建。

审批人是填写的名称，没有身份认证；本机制用于单机演示。模拟数据的复测结果明确标为 demo。导入数据的工单只接受新的 CSV 复测记录。

## HTTP 接口

默认入口 `http://127.0.0.1:8765`。JSON 使用 UTF-8；POST 需要 `Content-Type: application/json` 和从 bootstrap 获取的 `X-Agent-Token`。绑定 loopback 并验证 Host、Origin，以防其他网页直接提交本地请求。

| 方法与路径 | 请求 | 响应 |
|---|---|---|
| GET /api/bootstrap | 无 | token、数据集目录、检查目录、工单、知识与模型状态 |
| GET /api/dataset?id=mixed | 数据集 ID | 数据集元数据、设备快照、趋势 |
| GET /api/sample.csv | 无 | UTF-8 BOM 模拟模板 |
| POST /api/import | name、csv | 新数据集 ID、记录数；201 |
| POST /api/analyze | dataset_id、task | 检查记录；202，后台执行 |
| GET /api/runs/{id} | 检查 ID | 当前状态、工具记录、草案和证据 |
| GET /api/runs/{id}?format=md | 检查 ID | Markdown 报告下载 |
| POST /api/approve | run_id、proposal_id、approver | 已确认本地工单 |
| GET /api/orders | 无 | 所有工单 |
| GET /api/orders/{id} | 工单 ID | 含审计与复测的 JSON 下载 |
| POST /api/retest | order_id，以及 demo=true 或 csv | 工单、复测证据及最终状态 |

参数错误返回 400；请求来源或 token 不合法返回 403；未知路径 404。最多同时执行三个检查。前端不使用第三方脚本，所有数据渲染均进行 HTML 转义。数据库与源码路径不经 HTTP 暴露。

## 存储

`runtime/agent.sqlite3` 中有 datasets、runs、orders 三张表，分别保存数据批次、检查和工单。每次数据库使用后显式关闭连接，以适配 Windows 文件句柄管理。知识库是独立可审阅的 JSON 文件，模型密钥仅从进程环境变量读取。

数据库目前没有自动清理或多租户隔离。数据集列表最多显示 50 个，检查列表最多显示 200 个；旧记录仍存于数据库。需长期运行时应增加归档与容量控制。

## 已知限制

- “异常”表示演示规则下的待核查偏差，不是工程故障鉴定。
- 参考功率没有考虑朝向、倾角、各型逆变器效率曲线和校准误差。
- 时间戳统一使用项目当地时间，不接受混合时区；批次回放不等同实时采集。
- 当前是精确类型检索，没有向量索引、图谱推理或复杂语义检索。
- 默认自然语言解析仅提取 PV-数字编号，无法通用理解任意设备别名与复杂调度任务。
- 可选模型只做解释，尚未接入可自由规划的模型工具调用循环。
- 未实现通知、现场硬件控制、真实检修指令、用户权限、LoRA 或数字孪生。
- 未用真实工程数据验证准确率，不提供已量化的降本增效结论。
